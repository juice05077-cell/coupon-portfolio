一、项目背景与分析目标

1.1 项目背景

优惠券是 O2O 平台常用的营销工具，但优惠券被领取并不意味着最终完成核销。用户是否使用优惠券，可能与商户距离、优惠券类型、使用门槛、优惠力度以及自身消费需求等因素有关。

本项目基于天池 O2O 优惠券数据集，使用 SQL 进行数据清洗与行为分类，通过 Tableau 完成指标计算、可视化及分层分析，探索不同条件下的优惠券核销表现。

1.2 分析目标

本项目围绕一个核心问题展开：

什么条件下，用户领取的优惠券更容易被核销？

具体研究以下问题：

线下优惠券的整体领取与核销情况如何？

用户与商户的距离是否与核销行为有关？

不同优惠券类型、满减门槛和优惠力度下，核销表现有何差异？

不同商户优惠券组合的领取规模，是否会干扰对优惠力度与核销率关系的判断？

用户领取优惠券后，通常经过多长时间完成核销？

本项目关注的是核销行为的相关因素，而非直接证明优惠券对消费的因果促进效果。

二、数据来源与处理

2.1 数据来源

数据来自天池 O2O 优惠券数据集，主要使用线下数据进行分析。

原始字段包括用户 ID、商户 ID、优惠券 ID、折扣信息、距离、领取日期和消费日期。

其中，距离字段采用等级编码，不直接代表精确测量的距离。

2.2 数据清洗

使用 SQL 对原始数据进行整理，主要包括：

用户行为分类

依据优惠券领取记录和消费记录，将线下行为划分为：

领取并使用优惠券

领取优惠券但未使用

未领取优惠券而直接消费

通过区分上述行为，避免将无券消费错误计入优惠券领取量或核销量。

距离数据状态识别

对距离字段进行缺失值检查，并结合消费日期识别正常、普通缺失及异常缺失等数据状态。对于已发生消费但距离缺失的记录，单独标记为异常情况。在距离相关分析中排除无法判断距离的记录；其他分析则根据指标口径决定是否纳入。

优惠券特征处理

在 Tableau 中根据折扣信息区分满减券与折扣券。对于满减券，提取使用门槛、减免金额，并计算减免金额占使用门槛的比例；对于折扣券，则提取相应折扣档位。

核销时间处理

通过领取日期和消费日期计算领取至核销的间隔天数，用于观察核销时间分布。

2.3 核心指标

优惠券核销率定义为：

核销率 = 核销量 ÷ 领取量 × 100%

其中，领取量包括领取后使用和领取后未使用的优惠券记录；核销量仅包含已核销记录。

在进行领取规模分层分析时，采用各组核销量之和除以领取量之和计算整体核销率，避免直接平均不同商户优惠券组合的核销率。

01 / 观察结果

从距离分组结果看，优惠券核销率整体随距离等级增加而下降。其中，距离0级的核销率约为13.5%，距离1级降至约6%，此后下降幅度逐渐收窄；在距离8、9级出现小幅回升，距离10级则再次下降。

进一步观察发现，线下行为记录量随距离等级增加持续减少，说明远距离对应的消费及领券相关行为总体更少。但核销率并未完全遵循这一变化趋势，在部分远距离区间出现回升。

02 / 可能解释

这一现象可能与用户的消费目的有关：距离较远时，用户到店的便利性降低，而仍愿意前往特定商户的用户，可能具有更明确的消费需求或更强的商户偏好，因此部分远距离区间的优惠券核销比例并未持续下降。

03 / 业务参考

总体来看，距离与优惠券核销率存在明显的负向关联，但并非严格单调下降。对于线下优惠券运营，可以优先关注近距离用户的核销表现，同时进一步探索远距离用户的消费目的及商户吸引因素，为差异化投放提供参考。

从不同满减门槛的核销表现看，随着使用门槛提高，核销率总体呈下降趋势。

这一结果具有一定的业务解释空间：较高的最低消费要求可能限制优惠券的实际使用场景，使部分用户即使已经领取优惠券，也无法或不愿达到使用条件。

不过，满减门槛的实际限制程度还取决于商户的日常消费水平。例如，同样是满100元的优惠券，对于客单价不同的商户，可能意味着完全不同的使用难度。

因此，在为不同商户设计满减优惠券时，应结合各商户历史订单的消费金额分布，设置与用户日常消费水平相匹配的使用门槛，而非单纯追求较低的门槛或较大的减免金额。由于现有数据缺少订单金额，这一优化方向仍需进一步验证。

以商户与优惠券配置的组合作为分析单位，绘制优惠券领取数量与核销率的散点图，观察不同领取规模下的核销表现。

结果显示，不同组合之间的领取规模差异明显。领取量较少的组合，核销率分布较为分散，部分达到0%或100%；随着领取规模增大，核销率逐渐集中在相对较低的区间。

这一现象与核销率的计算方式有关。例如，当某组合仅有1次领取时，核销率只能是0%或100%；领取量较小时，少量核销记录的变化也可能造成较大的比例波动。因此，小样本组合中出现的极高或极低核销率，不一定代表稳定的核销表现。

这意味着，不同优惠券组合的核销率不仅存在差异，其结果的稳定程度也与领取规模有关。如果直接比较不同组合的核销率，容易将小样本产生的极端值误认为优惠券本身的优势或劣势。因此，下一步将按领取规模分层，进一步比较不同优惠力度下的核销表现。

为减少不同样本规模造成的干扰，根据单个商户优惠券组合的领取数量，将样本划分为1–9次、10–49次、50–99次、100–499次、500–999次及1000次以上六个层级。

在各领取规模层级内，进一步比较不同满减优惠比例对应的核销率。结果显示，即使在领取规模相近的组合之间，优惠力度与核销率也未呈现稳定的正向关系。

例如，在领取量达到1000次及以上的组合中，不同优惠比例对应的核销率约为1.83%～7.25%，并未随着优惠比例提高而持续上升。其他层级也存在类似的波动，部分较高核销率集中在领取规模较小的组合中。

这一结果说明，领取规模差异能够帮助解释部分极端核销率现象，但不足以完全解释优惠力度与核销表现之间的差异。优惠力度并非决定核销率的唯一因素，商户类型、商品价格及消费条件等仍可能共同影响结果。

因此，在优惠券设计中，不宜仅根据优惠比例大小判断核销效果，还应结合优惠券的领取规模与实际使用场景进行评估。

4.6 高优惠力度低核销率案例分析

典型案例：满30减20优惠券

在分析不同满减组合的核销表现时，发现“满30减20”优惠券的名义优惠力度较大，减免比例达到66.67%，但实际核销表现并不突出。因此，选取该优惠券作为典型案例，进一步检查其商户分布及相关用户行为。

首先，该优惠券的领取规模较小，整体核销率容易受到个别用户行为的影响，因此不能仅凭这一结果认定高额优惠缺乏吸引力。

进一步检查用户行为记录时，发现部分用户同时存在领取该优惠券但未核销，以及未使用优惠券直接消费的记录，其中部分行为发生在同一日期。

这一现象说明，未核销优惠券的用户并不一定完全没有消费行为。优惠券未被使用，可能与领取和消费的先后顺序、实际订单金额是否达到满减门槛，或优惠券的适用条件有关。

然而，现有数据缺少具体交易时间、订单金额及完整的优惠券适用规则，无法确认用户是否先消费后领券，也无法判断未核销是否由消费金额未达到门槛等因素造成。

因此，该案例不能证明大额优惠券缺乏吸引力，但提示我们：优惠力度并不能单独决定核销表现。分析异常核销率时，还需要结合样本规模、商户分布及用户实际消费行为进行判断。

通过计算优惠券领取日期与核销日期之间的间隔天数，观察已核销优惠券的使用时间分布。

从图中可以看出，核销记录主要集中在领取后的较短时间内，但领取当天的核销次数少于领取后第 1 天，随后核销次数整体呈下降趋势。这说明优惠券核销并非全部发生在领取当日，部分消费行为可能存在一定的决策与准备时间。

这一现象具有一定的业务解释空间：部分用户可能在已有消费计划的情况下领取优惠券，也可能因为获得优惠券而产生新的消费意愿，或调整原有的消费时间与安排。因此，优惠券的作用可能不仅体现在即时消费中，也可能与用户后续的消费决策有关。

但现有数据无法识别用户领取优惠券前的消费意愿，也缺少完整的订单信息，因此不能仅凭核销时间分布认定优惠券促成了新增消费。

此外，核销间隔分布仅反映已核销优惠券的时间特征，不能据此认定用户等待时间越长，核销意愿就越低，因为未核销优惠券并不包含在这一时间分布中。

从业务角度看，可以进一步关注领取后第 1 天及随后几天的用户行为，结合优惠券有效期、历史消费记录与提醒触达情况，探索优惠券对后续消费决策的影响及更合适的提醒时机。

六、主要结论与业务启示

6.1 主要发现

第一，商户距离与优惠券核销表现存在明显关联。

总体来看，距离较近的用户核销率更高，随着距离等级增加，核销率整体下降，但并非严格单调递减。这表明到店便利性可能是影响线下优惠券使用的重要因素，部分远距离用户也可能具有较明确的消费需求。

第二，满减门槛提高通常伴随着核销率下降。

不同满减门槛的核销率存在明显差异，较低门槛的优惠券整体表现更好。但由于不同门槛对应的商户、减免金额及消费场景可能不同，不能仅凭这一趋势认定门槛本身是核销率下降的直接原因。

第三，优惠力度与核销率之间不存在稳定的单调关系。

无论是具体满减组合还是折扣档位，更大的名义优惠力度都不一定对应更高的核销率。这说明优惠券的实际使用表现可能还受到使用门槛、消费条件及用户需求等因素影响，不能单纯依靠提高优惠力度判断优惠券效果。

第四，领取规模差异会影响核销率的观察与比较。

在领取规模较小的商户优惠券组合中，核销率容易出现极端值。按领取规模分层后，即使在相近规模的组合之间，优惠比例与核销率仍未呈现稳定的正向关系。因此，比较优惠券表现时，需要同时关注样本规模，避免将少量领取记录产生的高核销率误判为普遍规律。

第五，已核销优惠券的使用时间主要集中在领取后较短时期。

领取后第 1 天的核销次数高于领取当天，此后核销次数整体随间隔天数增加而减少。这提示部分优惠券可能并非用于即时消费，而是与用户后续的消费安排有关。但现有数据无法判断优惠券是否改变了用户原本的消费意愿。

6.2 业务启示

基于上述发现，可以提出以下值得进一步验证的优化方向：

1. 结合用户距离与消费需求，探索差异化的线下优惠券投放策略。

近距离用户具有较高的核销表现，可作为重点观察的用户群体。对于远距离用户，则可以进一步分析其消费频率、客单价及商户偏好，判断哪些用户具有较强的跨距离消费需求，而非仅依据距离决定是否投放优惠券。

2. 根据商户实际消费金额分布，优化满减门槛。

满减券的使用门槛应尽可能与用户日常消费水平相匹配，而非单纯追求较低的门槛或较大的减免金额。后续可结合商户历史订单金额，比较不同门槛与实际消费水平的匹配程度，并检验调整门槛后的核销表现。

3. 综合评估优惠力度、领取规模与实际使用表现。

评价优惠券时，不宜只比较名义折扣或核销率，还应同时关注领取数量、核销数量及商户差异。对于领取量较少但核销率较高的组合，应谨慎判断其代表性；对于大额优惠但核销率较低的组合，则可进一步排查使用条件与消费场景是否匹配。

4. 探索领取后的短期提醒与消费转化机制。

考虑到领取后第 1 天存在较多核销记录，可进一步研究用户领取优惠券后的消费决策过程，并结合优惠券有效期、历史消费行为及提醒触达数据，测试不同提醒时机的实际效果。

上述建议均基于现有数据中的关联性发现，属于有待验证的业务方向，尚不能直接视为已经证明有效的优化方案。

七、分析局限与后续方向

本项目主要存在以下局限：

缺少商品价格、订单金额和完整优惠券适用条件，无法判断用户未核销的具体原因。

不同优惠券之间存在商户、用户群体和消费场景差异，本项目仅按领取规模进行分层，仍无法完全排除其他因素的干扰。

部分优惠券组合领取量较少，核销率容易出现较大波动。

日期字段缺少具体时分秒，无法判断同一天领取与消费的先后顺序。

当前分析主要描述优惠券核销行为，无法直接估计优惠券带来的增量消费。

后续如能获取订单金额、商品类别、商户属性、优惠券有效期及更精细的用户行为数据，可进一步分析优惠券使用条件与实际消费需求的匹配程度。同时，通过设计合理的对照分析或营销实验，评估优惠券是否带来增量消费，而不仅是被原本具有消费需求的用户使用。

八、项目总结

本项目从优惠券整体核销情况出发，逐步分析距离、使用门槛、优惠力度和核销时间等因素。

在发现优惠力度与核销率不呈现稳定正向关系后，进一步检查不同商户优惠券组合的领取规模，通过散点图与分层热力图识别小样本极端值及规模差异对结果解释的影响。

分析过程中，重点区分了数据中能够直接观察到的现象与尚无法验证的解释，避免将相关关系直接认定为因果关系。

项目最终形成了一套基于 SQL 数据整理与 Tableau 可视化的优惠券核销行为分析成果。
